你的照片会怎么被处理

这一页讲清楚一件事：你上传的那张照片去了哪里、留多久、怎么删。 没有账号，没有第三方统计，也没有广告。

1. 你上传的照片

  • 照片会发到本服务自己的服务器上做测量，不经过任何第三方云服务。
  • 测量要用到照片里的像素值，所以压缩上传时保留的是颜色信息，不裁剪画面。
  • 测量完成后，照片是否留在服务器上，取决于你上传前那个勾选框：
    • 勾选：照片会归档保存，方便你之后回看这次结果。
    • 取消勾选：照片只在内存里处理完就丢弃，不写入磁盘，服务器上只留去掉了照片的测量结果。

2. 保存的话，留多久

  • 默认保留 30 天，到期自动清理。
  • 保存前会剥掉照片自带的拍摄信息（机型、GPS 等），只保留方向和拍摄时间——后者用于判断照片有没有被系统旋转过。
  • 不想留就别勾那个勾选框：取消勾选时，照片只在内存里处理完就丢弃， 服务器上只留下不含照片的测量结果。
  • 已经存下来之后想立刻删掉，可以在 GitHub 上提一个 issue，或直接联系服务提供者。

3. 每天的次数限制

  • 为了挡住批量刷和陌生人塞满这台机器的磁盘，每个人每天有测量次数上限。
  • 识别方式是浏览器指纹（由浏览器型号、屏幕尺寸、时区这类信息算出的一串编号）， 服务端只保存它的哈希值，不保存原始值，也不使用你的 IP 地址。
  • 这个编号每天更换一次，所以它不会变成一个长期跟踪你的标识。

4. 第三方会看到什么

  • 本站通过 Cloudflare 的隧道对外提供服务。因此 Cloudflare 会看到流量的元数据 （例如访问时间、来源 IP），但看不到照片内容——照片是加密传输后才解开的。
  • 除此之外没有任何第三方：没有统计脚本、没有广告、没有社交插件。

5. 我们不会做的事

  • 不把照片用于人脸识别、身份识别或任何形式的模型训练。
  • 不出售、不共享你的照片或测量结果。
  • 不建立与你真实身份的关联——本站没有账号系统，也不知道你是谁。

6. 关于测量结果

结果来自对单张照片的相机响应估计，会受到光线、手机型号和拍摄方式的影响。 它不能替代分光测色仪或专业色彩顾问，也不是医疗建议。 如果你要据此买粉底，建议再到专柜在颌线试三条色号对照一下。
